# 离线场景识别方案（待定）

状态：待评估，尚未选定或批准实施。关联 Comet Native 变更：`photo-pose-mvp`。

## 问题

当前客户端通过通用 MobileNet 输出的物体标签与关键词匹配来判断山景、公园、街道、室内；模型需联网获取，场景分类和加载均可能失败。用户希望评估运行时不依赖 LLM 或网络的场景识别。

## 候选方案

1. 选用适合端侧的场景分类模型，在本地识别山景、公园、街道、室内等有限类别。Places365 系列可作为候选，需要核实模型权重、数据与商业许可、格式、可转换性及体积，不代表已选型。
2. 姿态继续使用本地人体关键点模型；目标检测和分割仅在确实需要识别物体、背景区域时评估引入。
3. 用画面亮度及构图特征辅助推荐，但不能把纹理较少的区域当成可站立或安全区域。
4. 对低置信度结果显示候选并允许手动选择。模型及资源预先随应用提供或预下载完成后，推理时无需联网。

## 待验证

- 以用户提供的山景逆光照片及更多覆盖不同场景、天气、光照和遮挡的授权图片测试准确性、误判和低置信度表现。
- 比较候选模型在目标手机浏览器和设备上的模型大小、首次加载时间、内存、推理延迟及耗电；检验离线环境的真实表现。
- 评估模型、权重、标签及训练数据相关许可与产品使用范围。
- 明确是否需要识别登山杖、路牌、地面或背景区域，再决定是否引入其他检测或分割模型。
- 姿势素材的授权与覆盖度、人体遮挡和半身画面适配仍需处理。
