# 拍照姿势推荐 MVP 完整规格

## 相机与场景

### Requirement: 相机预览及异常
用户允许权限后，手机网页显示实时相机预览，支持切换前后摄像头。拒绝权限、设备不可用和资源加载失败时展示可理解的错误和恢复提示。

#### Scenario: 相机可用
- 当用户授权相机时，显示实时预览并可切换摄像头。
#### Scenario: 相机不可用
- 当权限被拒绝或设备不可用时，显示原因和重试提示，不显示虚假预览。

### Requirement: 场景推荐
客户端使用轻量视觉模型对相机画面抽帧分析，给出公园、街道或室内场景建议；用户可以随时手动切换。模型不可用或置信度不足时显示通用姿势并保留手动选择。实时画面不调用 LLM。

#### Scenario: 场景检测及修正
- 当模型输出足够可信的场景时显示建议，并允许用户手动覆盖。
- 当模型不可用或置信度不足时，显示通用姿势且手动选择可用。

## 姿势与引导

### Requirement: 姿势参考
按场景筛选最多三个单人姿势，展示参考图、简短动作说明和参考骨架。内置素材须明确标明示意性质，不假称真实授权图片。

#### Scenario: 选择姿势
- 当用户选择姿势时，显示参考图、动作说明及参考关键点构成的骨架。

### Requirement: 姿态叠加与纠正
在用户选择姿势后，通过端侧人体关键点模型显示当前人体骨架和参考轮廓。按人体框归一化位置和尺度，并处理前后摄像头镜像及左右方向；根据关键点可靠性逐次给出最多一条位置、手臂、腿部或身体倾斜提示。关键点不可见或质量不足时提示调整入镜，不给出虚假纠正。

#### Scenario: 姿态可识别
- 当人物关键点可靠且与参考姿势有明显差异时，在预览上展示骨架与最多一条纠正提示。
#### Scenario: 姿态不可识别
- 当人物未入镜或关键点不足时，提示调整距离或让身体入镜；不输出具体动作纠正。

## 拍摄和素材

### Requirement: 本地拍摄
用户可拍照预览并保存；默认不将相机画面或照片上传服务端。

#### Scenario: 完成拍摄
- 当用户拍照后，可预览照片并保存到设备。

### Requirement: 素材准备
人工寻找公园、街道、室内各 5～10 张姿势图片候选并记录来源、作者和授权状态；国内图库或社交平台可用于寻找候选，不绕过平台限制。只将已确认允许产品展示、本地模型解析且具备必要肖像许可的真实图片入库；授权未确认时保留候选清单，使用标明性质的示意素材补足。由本地 Codex 离线查看素材并生成场景、姿势、景别与动作描述等标签，人体姿态模型提取参考关键点并进行人工审核。支持本地导入图片、标签和参考关键点。

#### Scenario: 审核素材
- 当导入有效授权素材及其关键点时，姿势可在对应场景中被推荐；数据不完整时给出可理解的反馈。

#### Scenario: 收集候选与本地解析
- 每类场景记录 5～10 张候选的来源和授权状态；只对允许解析的素材由本地 Codex 生成标签，人工核对并保存参考关键点。
- 授权不足时不将候选作为产品素材使用，并说明缺口。

### Requirement: 开发运行
提供项目安装、运行、自动检查及手机 HTTPS 测试说明，记录模型资源和网络要求。

#### Scenario: 开发者启动
- 当依照文档安装依赖并启动项目时，可访问应用并执行自动检查。
