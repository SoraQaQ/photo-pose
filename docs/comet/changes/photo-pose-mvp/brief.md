# 目标

提供可在手机浏览器体验的拍照姿势推荐 MVP：根据相机场景推荐姿势，叠加人体骨架并给出基础纠正，辅助用户拍照。

# 范围

- 单人手机 H5，浏览器授权后启用前后摄像头；相机不可用时给出明确提示。
- 客户端使用轻量视觉模型分析公园、街道、室内三类场景，提供手动修正和识别不确定时的通用推荐；相机画面不调用 LLM。
- 选择参考姿势后显示参考图、文字和骨架，检测当前人物关键点，给出位置、手臂、腿部及倾斜的基础纠正；低置信度或关键点缺失时提示重新入镜。
- 网页拍照并保存；图像数据默认留在本地设备。
- 收集公园、街道、室内各 5～10 张适合模仿的图片候选，记录来源、作者和授权状态；仅将已确认允许产品展示及本地解析、且具备必要肖像许可的真实图片入库。可在国内图库与社交平台人工寻找，不绕过平台限制；授权不足时保留候选清单并使用明确标识的示意素材。由本地 Codex 离线查看图片并生成场景、姿势、景别、动作描述等标签；人体关键点由姿态模型提取并经人工审核。
- 可在手机 HTTPS 环境运行；提供本机启动和手机测试说明。

## 目录结构

### 新建
- `src/` — 手机网页、相机和模型加载、推荐与姿势纠正逻辑。
- `public/` — 演示参考素材及模型静态资源配置。
- `tools/` — 授权素材离线准备或导入工具。`docs/` — 素材候选来源、授权状态和审核记录。
- `tests/` — 推荐及姿态纠正等关键逻辑验证。
- `package.json`、构建配置与 `README.md` — 依赖、运行和测试说明。

### 修改
无，项目当前没有应用代码。

### 删除
无。

### 明确不建
- 服务端、账户和云端存储 — 首版数据在本地处理。
- 社交平台爬虫 — 素材需要明确授权，首版使用示意素材和授权导入。

# 非目标

不实现双人姿势、姿态精确评分、自动拍照、自动大规模抓图、用户画像、正式商用素材采购或应用商店上架。

# 验收示例

- A1：手机浏览器允许相机权限后能看到预览；拒绝或设备不可用时有可理解的提示；可切换前后摄像头。
- A2：画面能通过端侧分类模型给出场景建议，用户可选择公园、街道、室内；低置信度或模型失败时可手动选择且展示通用推荐。
- A3：选择场景后显示最多三个对应姿势；选择姿势可查看标明来源性质的参考图、动作文字及参考骨架。
- A4：人物入镜时显示当前骨架和参考轮廓，并按可见关键点给出最多一条位置或动作纠正；关键点不足时给出重新入镜提示；左右镜像保持一致。
- A5：用户能够拍照并保存，拍摄不要求上传画面；模型或相机错误时提示且页面不崩溃。
- A6：提供三类场景各 5～10 张候选图的来源和授权状态清单；仅将授权齐备的真实图片入库，不足时明确展示示意素材。支持导入授权图片与标签、参考关键点；由本地 Codex 离线解析标签并记录人工审核方式。
- A7：项目能按文档安装、启动并运行相关自动检查，说明 HTTPS 和模型资源加载要求。
